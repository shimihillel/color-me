# Color Me v28 — More Easy Accents

מה חדש:
- ספריית הקישוטים הורחבה מ-8 ל-19 קישוטים קלים.
- קישוטים יכולים להופיע על ציפורן אחת, שתי ציפורניים או כל היד.
- נוספו מיקומים ודוגמאות: נקודה בבסיס/בקצה, נקודה גדולה, שורה אנכית, אלכסון, אשכול בפינה, נקודות על כל היד, קונפטי על כל היד ודובדבנים על שתי ציפורניים.
- תדירות הקישוטים עלתה לכ-10% מההצעות.
- המנוע נמנע מלחזור על אותו קישוט בארבע ההצעות האחרונות.
- מגנטי נשאר אחיד תמיד וללא קישוט.
