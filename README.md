# Color Me v27 — Easy Accents

מה חדש:
- בערך 6% מההצעות הן עכשיו הצעות עם קישוט קל.
- הקישוטים מופיעים אוטומטית, בלי מסך בחירה נוסף.
- נוספו: נקודה אחת, נקודות קטנות, קונפטי, שתי נקודות דובדבן ואקצנטים על אצבע אחת או שתיים.
- ההוראות כוללות איפה לעשות את הקישוט ורמת קושי.
- מגנטי נשאר אחיד תמיד וללא קישוטים.
- ספריית 256 הגוונים ושילובים של 2–5 צבעים נשמרו.
