# Color Me 💅

אפליקציית Web בעברית לבחירת מריחת הלק הבאה שלך.

## מה יש בפנים
- שם חדש: **Color Me**
- מסך ראשי עם יד וציפורניים שמשתנות לפי ההצעה
- כפתור **הבא בתור** עם אנימציית הגרלה
- כפתור **שומרת** ששומר את המריחה ומעדכן את המריחה האחרונה
- כרטיס ימים מהמריחה האחרונה:
  - עד 14 יום: עדיין טרי
  - 15–20: מתחיל להתקרב
  - 21+: זמן להחליף
  - 28+: שימי, די, להחליף 😄
- מסך **מריחות שאהבתי**
- מסך **הנתונים שלי** פשוט וחמוד
- מסך **איזה צבע בא לי** עם משפחה + גוון ספציפי + כפתור **לכי על זה**
- אייקון חדש: CM צבעוני + טיפת לק

## כללי המנוע
- 60% אחיד
- 40% טוויסט
- בלי פרנץ׳
- בלי מאט
- בלי אומברה
- מעט מאוד ניוד
- כן לצבעים חיים, כהים, גליטר, מטאלי ומגנטי
